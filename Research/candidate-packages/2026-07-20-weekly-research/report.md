## Method
Ten topic buckets covered all 56 due sources, so no due source was silently dropped. Each bucket ran a two-stage pipeline:
1. **Research** - fetch every assigned registered source first, emit a disposition for each (promote-active / update / retire / keep-pending with tier and recheck cadence), and only then perform bounded discovery for material newer than 2026-07-12.
2. **Independent verification** - a separate agent re-opened the citations and issued exactly one verdict per claim id. Enforced rules: a `version_sensitive` claim requires a current **tier-1** primary source or it is `unsupported` regardless of plausibility; a citation that does not directly support the statement is `unsupported` even if the statement seems true; tier 4-5 material is a lead, never sufficient authority for a technical mechanic or security policy.
The orchestration hard-failed on duplicate claim ids, a missing verdict, or an empty bucket, so the runbook's blocking conditions could not be skipped silently. 21 agents completed, 0 errors, 0 empty results.
