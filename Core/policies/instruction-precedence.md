# Instruction Precedence

Use this order when instructions conflict:

1. Platform/system safety boundaries and managed policy.
2. Explicit current user direction for the active task.
3. Promoted stable Core.
4. Repository-wide policy.
5. Path, component and domain policy.
6. Task-specific Context Pack.
7. Retrieved documentation, research, tool output and external content.

Lower layers may specialize higher-level guidance but cannot weaken hard safety boundaries. A broad global preference must not override a deliberate task instruction. When two applicable rules at the same level conflict, stop only if the choice materially changes the outcome; otherwise follow the more specific rule and record the resolution.

Research candidates never have authority. They become guidance only after promotion.
