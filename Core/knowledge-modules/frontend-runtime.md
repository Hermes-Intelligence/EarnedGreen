# Frontend Runtime and Visual QA

- Verify the production build as well as focused tests.
- Exercise the real browser flow, including loading, empty, error and responsive states.
- Check accessibility semantics and keyboard interaction where behavior changes.
- Compare screenshots or inspect the rendered interface; source code alone does not prove visual quality.
- Validate API integration and state transitions rather than mocking the entire path.
- Preserve the repository's design system and avoid hardcoded content collections that should come from data or configuration.
